










# Bike Share Dashboard

Power BI dashboard analyzing bike-share revenue, profit, and rider behavior
to answer: "When are we making the money?"

## Tools
- MySQL (data prep & VIEW)
- Power BI

## Key Insights
- Revenue and profit trends over time
- Revenue by season
- Registered vs. casual riders
- Revenue by hour

## Files
- `Bike_Share_Dashboard.pbix`: Power BI report
- `bike_share_view.sql`: SQL view used as the data source
